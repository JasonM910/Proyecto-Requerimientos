# Proyecto Requerimientos - Catering Services

Prototipo visual desarrollado para el curso de Requerimientos de Software del Tecnológico de Costa Rica, Campus Tecnológico Local San Carlos.

## Descripción

Catering Services es una propuesta de aplicación web orientada a la consulta y solicitud de servicios de catering para diferentes tipos de eventos.

El proyecto se desarrolla progresivamente mediante sprints. El prototipo visual se utiliza como apoyo para identificar, analizar y refinar los requerimientos del sistema.

## Tecnologías utilizadas

- React
- Vite
- JavaScript
- Bootstrap
- React Bootstrap
- React Router DOM

## Requisitos

Antes de ejecutar el proyecto se debe tener instalado:

- Node.js
- npm
